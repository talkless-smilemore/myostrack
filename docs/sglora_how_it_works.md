## 1. 问题背景

### 1.1 微调的困境

在反无人机跟踪任务中，预训练的 ViT backbone（MAE 自监督训练 + OSTrack 跟踪预训练）面临领域偏移：

- **外观域迁移**：RGB → 红外（IR），颜色和纹理统计量完全不同
- **视角迁移**：水平拍摄 → 俯瞰/仰视，空间布局改变
- **尺度迁移**：通用目标（几十到几百像素）→ 微型无人机（10~50 像素）

完全微调 12 层 ViT-Base（约 86M 参数）会导致：
- 在小数据集上严重过拟合
- 灾难性遗忘——丢失预训练学到的通用视觉知识
- GPU 显存和训练时间成本高

### 1.2 现有方法的各自局限

**OPLoRA**（Xiong & Xie, AAAI-26）：
- 对冻结权重 W₀ 做 SVD，在 top-k 奇异向量的正交补空间内放置低秩适配器
- 优点：保护预训练主成分方向
- 缺点：所有输出神经元均等参与，不做选择性适配

**NeuroAda**（Zhang et al., EMNLP 2025）：
- 选择部分神经元（按权重幅值排序），仅对这些神经元做稀疏微调
- 优点：参数效率高
- 缺点：选择依据来自权重幅值（与任务无关），没有空间保护机制

**NS-OPLoRA**（之前的融合尝试）：
- 简单叠加：OPLoRA 的正交投影 → 再加 NeuroAda 的静态二进制掩码
- 问题：两者是独立的、时序叠加的，没有真正的交互

### 1.3 SGLoRA 的设计目标

> **让正交投影和神经元选择共享同一个信息源（SVD），并通过可学习机制深度融合，使读者看不出是两个方法拼接的产物。**

## 2. 核心思路

### 2.1 一句话总结

SGLoRA = **完整的 OPLoRA 正交骨架（输入投影 P_R + 输出投影 P_L）+ 一个可学习的频谱门控向量 g 替代 NeuroAda 的静态硬掩码**。

### 2.2 三个关键决策

| 决策 | 内容 | 依据 |
|------|------|------|
| **保留 P_R + P_L** | OPLoRA 的完整正交投影骨架 | P_L 不只是"保护主成分"，而是从数学上保证 ΔW 的列空间与 W₀ 的主成分子空间正交——删了它等于删了 OPLoRA 最核心的贡献 |
| **替换 M → g** | 静态二进制掩码 → 可学习软门控 | 软门控能在训练过程中自适应地决定每个输出神经元的参与度，而不是在训练前就拍板 |
| **中性初始化** | g 从 0.5 起步，不分高低贵贱 | P_L 已经在保护主成分了，门控无需重复这个工作。0.5 意味着"先看看再说" |
| **动态熵调度** | 先学习，后稀疏 | 早期自由探索哪些神经元有用，后期通过熵正则推往 0/1 二值化 |

## 3. 数学公式

### 3.1 完整前向传播

给定输入 $x \in \mathbb{R}^{B \times N \times d_{in}}$：

$$
\begin{aligned}
y_{\text{frozen}} &= x W_0^\top + b \\[4pt]
x_r &= x - (x V_k) V_k^\top = P_R \cdot x \quad\text{其中 } P_R = I - V_k V_k^\top \\[4pt]
z   &= x_r A^\top \quad\text{其中 } A \in \mathbb{R}^{r \times d_{in}} \\[4pt]
u   &= z B^\top \quad\text{其中 } B \in \mathbb{R}^{d_{out} \times r} \\[4pt]
u_r &= u - (u U_k) U_k^\top = P_L \cdot u \quad\text{其中 } P_L = I - U_k U_k^\top \\[4pt]
u_g &= g \odot u_r \quad\text{其中 } g = \sigma(s),\; s \in \mathbb{R}^{d_{out}} \\[4pt]
y   &= y_{\text{frozen}} + \frac{\alpha}{r} \cdot u_g
\end{aligned}
$$

### 3.2 等效权重更新

训练后可将适配器合并回权重矩阵，推理时零额外开销：

$$
W_{\text{merged}} = W_0 + \frac{\alpha}{r} \cdot \text{diag}(g) \cdot P_L \cdot B \cdot A \cdot P_R
$$

### 3.3 训练损失

$$
\mathcal{L} = \mathcal{L}_{\text{task}} + \lambda_e(t) \cdot \bar{H}(g) + \lambda_g(t) \cdot \frac{1}{d_{out}}\sum_{i=1}^{d_{out}} \|B_{i,:}\|_2
$$

其中：

$$
H(g) = -g\log g - (1-g)\log(1-g) \quad\text{（二元熵，最小化 → g→0 或 g→1）}
$$

## 4. 逐组件解析

### 4.1 冻结通路（W₀ + b）

- **来源**：MAE 自监督预训练 + OSTrack 跟踪预训练
- **状态**：完全冻结，不参与梯度计算
- **作用**：提供稳定的基础表示，所有微调以残差形式叠加

### 4.2 输入正交投影 P_R

$$P_R = I - V_k V_k^\top$$

- **V_k**：W₀ 的 top-k 右奇异向量（$k = 16$），一次性 SVD 计算后冻结
- **作用**：将输入 $x$ 投影到 W₀ 主成分方向的正交补空间
- **直觉**：如果 $x$ 中有一部分信号是 W₀ 已经能很好处理的（沿 $V_k$ 方向），适配器就不需要再看这部分——专注于"新颖"信号

### 4.3 低秩变换 A → B

- **A**：$\mathbb{R}^{r \times d_{in}}$，将投影后的输入压缩到低秩空间（瓶颈）
- **B**：$\mathbb{R}^{d_{out} \times r}$，从低秩空间恢复到输出维度
- **秩 r**：由层重要性和注入目标决定（2/4/6/8）

### 4.4 输出正交投影 P_L

$$P_L = I - U_k U_k^\top$$

- **U_k**：W₀ 的 top-k 左奇异向量，一次性 SVD 计算后冻结
- **作用**：将适配器的输出从 W₀ 主成分方向投影掉
- **直觉**：确保适配器产生的更新不会"污染"预训练特征空间中最关键的方向

### 4.5 频谱门控 g

详见 [第 5 节](#5-门控机制)。

## 5. 门控机制

### 5.1 参数化

$$g = \sigma(s), \quad s \in \mathbb{R}^{d_{out}}$$

- 每个输出神经元有一个可学习的标量参数 $s_i$
- $\sigma$ 是 sigmoid 函数，将 $s_i$ 映射到 $(0, 1)$
- $g_i$ 的含义：神经元 $i$ 的适配信号通过比例

### 5.2 初始化为中性

$$s_i = 0 \quad\Rightarrow\quad g_i = \sigma(0) = 0.5$$

**为什么不基于 SVD 谱重要性初始化？**

早前版本尝试了 $g_i^{\text{init}} = 1 - \frac{\sum_j \sigma_j |U_{i,j}|}{\max(\text{imp})}$，即主成分神经元初始门控低。结果比纯 OPLoRA 差 2 个点。

**原因**：P_L 已经从数学上消除了 $U_k$ 方向的成分。门控再去压制"主成分神经元"就是双重惩罚——这些神经元被 P_L 处理后，残差信号本就不在主方向上了，但门控仍然压制它们。

**修正**：所有门控从 0.5 起步。P_L 负责"保护主成分"，门控负责"发现哪些神经元的残差信号对任务有用"——两者分工明确。

### 5.3 门控的渐变过程

```
训练早期 (warmup, λ=0):
  g ≈ 0.3~0.7  门控在数据驱动下自由探索
  
训练中期 (anneal):
  g → 0.05 或 0.95  熵正则开始将门控推往二值
  
训练后期 (full λ):
  g → ≈0 或 ≈1  近似二值，可直接用于模型压缩
```

### 5.4 门控 ≠ P_L

关键区分：

| | P_L | 门控 g |
|---|---|---|
| **操作维度** | 方向空间（沿 U_k vs 正交） | 神经元（逐输出维度） |
| **作用** | 消除主成分方向的成分 | 缩放每个神经元的整体输出 |
| **粒度** | 向量投影（全局） | 标量乘法（逐神经元） |
| **状态** | 冻结 | 可学习 |
| **效果** | "不往主方向写" | "少写甚至不写给不重要的神经元" |

一个直觉比喻：
- P_L 是一个**方向滤波器**——"不管多少，这个方向的东西全部过滤掉"
- g 是一个**神经元音量旋钮**——"这个神经元的声音开多大"

## 6. 熵正则化调度

### 6.1 为什么需要调度

直接加熵正则的问题是：训练早期门控还在探索阶段，熵惩罚会**过早地将门控推向 0**，导致大量神经元永久关闭——LoRA 路径直接失效。

### 6.2 三段式调度

```
λ(t) = λ_max · clamp((t - warmup) / anneal, 0, 1)

      λ
      ↑
1e-4  │                    ┌──────────
      │                   ╱
5e-5  │                  ╱
      │                 ╱
      │                ╱
  0   └────────────────┴──────────────→ epoch
      0     warmup    warmup+anneal   40
           (0.33)      (0.33+0.33)
```

| 阶段 | epoch 范围 (总40) | λ_e | 门控行为 |
|------|-------------------|-----|---------|
| 自由学习 | 0 ~ 13 | 0 | 无约束，数据驱动 |
| 渐进收紧 | 13 ~ 26 | 0 → 5e-5 | 逐步推往二值 |
| 完全正则 | 26 ~ 40 | 5e-5 | 近似二值，可压缩 |

### 6.3 熵的作用

最小化 $H(g)$ 的效果：

- $g_i \to 0$：神经元 $i$ 的适配输出被关闭 → 节省参数/计算
- $g_i \to 1$：神经元 $i$ 的适配输出全量通过 → 重要的神经元
- $g_i \approx 0.5$ → $H(0.5) = \log 2 \approx 0.693$：最大熵 = 最大不确定性 → 被惩罚

### 6.4 行 group-lasso 的辅助作用

$$\|B_{i,:}\|_2 \quad\text{—— B 的第 i 行 L2 范数}$$

- 如果神经元 $i$ 不重要，$B_{i,:}$ 整行趋于 0
- 与熵正则互补：熵推 $g_i \to 0$（关闭输出），group-lasso 推 $B_{i,:} \to 0$（关闭参数）
- 两者叠加的效果远好于单一正则

## 7. 层选择策略

层选择基于 OSTrack_Layer_Analysis.md 的扰动实验数据，综合考虑两个维度：

| 维度 | 含义 | 来源 |
|------|------|------|
| **综合敏感度** | PatchShuffle + GaussBlur + PhaseScramble | 该层对三类扰动的总响应量 |
| **功能角色** | CE 决策点 / 融合枢纽 / 局部关联 / 稳定输出 | 扰动模式分布 + 架构位置 |

### 7.1 注入策略

```
B0  B1  B2  B3★  B4  B5  B6★  B7  B8  B9★  B10  B11
❄   🟢  🟣  🟡   ❄   🟣  🟡   🟢  🟠  🟡   ❄    ❄
```

| 层                | 秩   | 目标               | 核心理由                            |
| ---------------- | --- | ---------------- | ------------------------------- |
| **B7** 融合枢纽      | 8   | qkv+proj+fc1+fc2 | 纹理+结构双轨融合，综合敏感度 #2              |
| **B1** 纹理点火      | 8   | qkv+proj+fc1+fc2 | PatchShuffle 4.6× 跳变，局部关联入口     |
| **B6** CE-2 综合决策 | 8   | qkv+proj         | 全模型 #1，GaussBlur 峰值，三指标均衡       |
| **B9** CE-3 纹理筛选 | 8   | qkv+proj         | PatchShuffle 峰值 0.713，外观迁移核心    |
| **B3** CE-1 空间筛选 | 8   | qkv+proj         | CE 入口，结构敏感性主导                   |
| **B5** CE 后重建    | 4   | fc1+fc2          | CE 剪枝后在稀疏 token 上重建局部关联         |
| **B2** 全局空间      | 4   | fc1+fc2          | 跨 fragment 构建空间布局，新视角适配         |
| **B8** 纯局部纹理     | 2   | qkv+proj         | 遮挡场景关键（PhaseScramble 最低=不看整体结构） |

### 7.2 冻结策略

| 层 | 理由 |
|----|------|
| **B0** | patch embedding，无 transformer 学习能力，纯投影 |
| **B4** | 过渡精炼层，gap 仅 +0.096，"敏感性不高，可以冻结" |
| **B10** | 细化微调层，综合敏感度尚可但优先级 ⭐ |
| **B11** | "扰动不敏感，特征已成形" |
| **B10/B11** | 离 head 最近的层通用性强，冻结可防过拟合 |

### 7.3 为什么不全量注入

1. **过拟合风险**：反无人机数据集规模有限，12 层全注入参数过多
2. **深层通用性**：B10/B11 处理的语义信息跨领域变化小，冻结反而保护泛化
3. **SGLoRA 的 gate 可在已注入的 8 层内做更细粒度的选择**，无需在所有层都注入

## 8. 训练与推理

### 8.1 训练流程

```
1. 加载预训练 ViT (MAE + OSTrack 跟踪预训练)
2. 遍历注入配置，将指定层的 nn.Linear 替换为 SpectralGatedLinear
3. 每层独立做 SVD → 缓存 U_k, V_k
4. 门控初始化为 0（→ g=0.5）
5. 前向传播：冻结通路 + SGLoRA 通路（P_R → A → B → P_L → gate）
6. 计算损失：L_task + L_reg (entropy + group-lasso)
7. 每 epoch 开始时更新 SpectralGatedLinear.set_progress(epoch/max_epochs)
8. 正则化强度根据 progress 自动调度
```

### 8.2 推理流程

```
训练完成后：
1. 对每个 SpectralGatedLinear 调用 merge_to_weight()
2. W_merged = W₀ + (α/r)·diag(σ(s))·P_L·B·A·P_R
3. 替换为标准 nn.Linear(W_merged, bias)
4. 推理时零额外参数、零额外计算
```

### 8.3 关键超参数

| 参数 | 值 | 说明 |
|------|-----|------|
| rank | 2/4/6/8（按层） | LoRA 低秩维度 |
| top_k | 16 | SVD 保留的奇异向量数 |
| alpha | 8.0 | 适配器缩放因子 |
| entropy_lam_max | 5e-5 | 熵正则峰值强度 |
| group_lasso_lam_max | 1e-5 | 行稀疏正则峰值强度 |
| warmup_ratio | 0.5 | 无正则化的训练比例 |
| anneal_ratio | 0.25 | 正则化渐增强的比例 |

## 9. 与 NS-OPLoRA 的对比

| 维度 | NS-OPLoRA | SGLoRA |
|------|-----------|--------|
| **正射投影** | P_R + P_L 均保留 | P_R + P_L 均保留 |
| **门控类型** | $M \in \{0,1\}$ 硬掩码 | $g = \sigma(s) \in [0,1]$ 软门控 |
| **门控来源** | $\text{mean}(|W_0|, \text{dim}=1)$ 权重幅值 | 中性初始化（全 0.5），从数据学习 |
| **门控状态** | ❄ 静态，训练前确定 | ★ 可学习，随训练演化 |
| **稀疏化** | 固定 `neuron_keep_ratio`（如 0.8/0.6/0.5） | 熵调度 + group-lasso，数据驱动 |
| **门控与 P_L 的关系** | 无交互，时序叠加 | 门控在 P_L 之后，互补不重复 |
| **P_L 与门控的定位** | P_L 保护主成分，门控压制主成分神经元 → 双重惩罚 | P_L 保护主成分，门控选择残差神经元 → 分工明确 |
| **层选择** | B0-5 + B3,6,9（8 层，含 B0 的无效注入） | B1,2,3,5,6,7,8,9（8 层，证据驱动） |
| **关键修正** | ❄ B7 错误冻结 | 🟢 B7 正确注入（综合敏感度 #2） |
| **公式外观** | 明显是 "OPLoRA + NeuroAda 拼接" | 统一公式，不可分割 |
