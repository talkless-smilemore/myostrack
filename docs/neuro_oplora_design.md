# NS-OPLoRA: Neuron-Selective Orthogonal Projection LoRA

## 融合 OPLoRA 与 NeuroAda 的层自适应参数高效微调

### 面向反无人机 (Anti-UAV) 跟踪任务

---

## 1. 背景

### 1.1 两个方法的原始设计

**OPLoRA** (Xiong & Xie, AAAI-26)：
- 对 frozen 权重矩阵 W 做 SVD，提取 top-k 奇异向量 U_k, V_k
- 在奇异向量张成的**正交补空间**内放置低秩适配器
- ΔW = (α/r) · P_L · B · A · P_R，其中 P_L = I - U_k·U_k^T, P_R = I - V_k·V_k^T
- 设计动机：保护预训练主成分方向，只在"边角"空间学习任务特定知识
- 当前应用：全部 12 层的 qkv/proj/fc1/fc2，rank=8, top_k=16

**NeuroAda** (Zhang et al., EMNLP 2025)：
- 每个神经元（权重矩阵的一行）选出幅值最大的 top-k 个输入连接
- 对这些选中的连接引入 bypass（Δ 值，初始化为 0），仅优化这些 Δ
- 设计动机：保证每个神经元至少有一个可训练连接，激活全网络的适应潜力
- 关键发现：只要让所有神经元都能改变激活状态，就能有效适应下游任务
- 内存优势：无需 mask，只存储 k×d_out 个稀疏值 + 索引

### 1.2 为什么需要融合

| 维度 | OPLoRA | NeuroAda | 互补性 |
|------|--------|----------|--------|
| 更新空间 | 正交子空间（全局） | 任意位置（逐神经元） | OPLoRA 确定了"在哪更新"，NeuroAda 确定了"谁值得更新" |
| 粒度 | 层级低秩矩阵 | 神经元级稀疏 Δ | 低秩结构保证参数效率，稀疏选择保证针对性 |
| 神经元参与 | 全部神经元均等参与 | 每神经元 k 个连接 | 可以结合：选哪些神经元 + 每个神经元更新多少 |
| 预训练保护 | SVD 主成分保护 | 原始的 frozen W+Δ 模式 | OPLoRA 的空间保护是 NeuroAda 没有的 |

直接叠加（ΔW = ΔW_oplora + ΔW_neuroada）的问题：
1. 两个独立模块可能学习相互抵消的更新
2. OPLoRA 对"惰性神经元"和"关键神经元"同等对待，浪费参数
3. NeuroAda 的稀疏更新可能落在主成分方向上，与 OPLoRA 保护机制冲突

融合的正确方式：**用 NeuroAda 的选择逻辑指导 OPLoRA 的更新分配，而非并行叠加。**

## 2. OSTrack Block 逐层功能分析

### 2.1 12 层 ViT-Base 的层次化特征

```
模板(z) + 搜索(x) token 拼接 → 12 层 joint self-attention → box head
                    ↑ CE@3      ↑ CE@6      ↑ CE@9
```

| Block | 阶段 | 关注内容 | 对反无人机任务的重要性 |
|-------|------|---------|---------------------|
| 0-2 | 浅层 | 局部纹理、边缘、颜色匹配 | ★★★ 小目标依赖局部细节 |
| 3 | CE-1 | 第一次剪枝，排除明显背景 | ★★★ 快速锁定搜索范围 |
| 4-5 | 中层 | 部件结构、轮廓形状 | ★★ 结构保留 |
| 6 | CE-2 | 第二次剪枝，精细筛选 | ★★★ 快速目标定位 |
| 7-8 | 中深层 | 物体级语义、全局上下文 | ★ 小目标语义信息少 |
| 9 | CE-3 | 第三次剪枝，最终聚焦 | ★★ 精确定位关键 |
| 10-11 | 深层 | 抽象语义、全局形状 | ☆ 小目标几乎贡献-，冻结反而防过拟合 |

### 2.2 反无人机任务的特殊性

| 特性 | 含义 | 对层的影响 |
|------|------|-----------|
| **小** | 目标仅占 10-50 个 patch token | 浅层局部特征是唯一可靠的匹配依据；深层语义对几像素目标无意义 |
| **快** | 帧间位移大，尺度/视角变化剧烈 | CE 剪枝层的质量决定能否快速聚焦；搜索区域需要更精确的 attention |
| **UAV 视角** | 俯瞰/仰视，与 ImageNet 分布差异大 | 需要适应新视角的纹理/形状，但不改变基础视觉概念 |

## 3. NS-OPLoRA 融合方案

### 3.1 核心公式

标准的 OPLoRA 前向（行向量形式）：

```
x_r = x - (x·V_k)·V_k^T          (1) 输入侧正交投影
z   = x_r·A^T                     (2) 降维 r×d_in → r
u   = z·B^T                       (3) 升维 r → d_out
u_r = u - (u·U_k)·U_k^T          (4) 输出侧正交投影
out = x·W^T + b + scale · u_r    (5) 残差输出
```

NS-OPLoRA 在步骤 (4) 和 (5) 之间插入**神经元选择性掩码**：

```
u_r  = u - (u·U_k)·U_k^T         (4) 同上
u_r' = M ⊙ u_r                    (4.5) 神经元级选择
out  = x·W^T + b + scale · u_r'  (5') 残差输出
```

其中 M ∈ {0,1}^{d_out} 是一个固定的二进制掩码：

```
M[i] = 1  当 i ∈ TopK(importance, ceil(d_out × p))
M[i] = 0  否则

importance[i] = mean(|W[i,:]|)     // 神经元 i 所有输入连接的平均幅值
```

### 3.2 设计要点

#### 要点 1：M 是静态且固定的

- 在初始化时根据 frozen W 计算，训练过程中不变
- 与 NeuroAda 一致：选择依据来自预训练权重，任务无关
- 不需要额外存储完整的 mask 比特图（可以用索引列表压缩），但在这种规模下直接存 buffer 即可

#### 要点 2：梯度隔离

被 mask 掉的神经元（M[i]=0）：
- u_r'[i] = 0，无论 B、A 如何变化
- ∂L/∂B[i,:] = 0（B 的该行不收梯度）
- ∂L/∂A 只来自被选中神经元通过 B 的反向传播

效果：训练时 B 矩阵中被 mask 的行保持零初始化状态，**不消耗优化器状态和梯度内存**。

#### 要点 3：推理时 merge

训练后，将学习到的更新 merge 回原权重：

```
W_merged = W + scale · diag(M) @ B @ A
        = W + [m_1·(B@A)_1; m_2·(B@A)_2; ...]
```

其中被 mask 的行贡献为零，恢复为标准 nn.Linear，推理无额外开销。

### 3.3 各层配置策略

```
Block 0-2 (浅层 — 关键):
  neuron_p = 0.8     # 80% 神经元参与适应
  rank = 8            # 较大的低秩空间
  targets = [qkv, proj, fc1, fc2]  # 全量适配
  理由: 小 UAV 的纹理/边缘匹配需要充分适应新视角

Block 3, 6, 9 (CE 剪枝层 — 聚焦):
  neuron_p = 0.6     # 60% 神经元
  rank = 4            # 中等秩
  targets = [qkv, proj]  # 重点关注注意力
  理由: CE 依赖 template→search attention，调 attn 最有效

Block 4, 5 (中层 — 过渡):
  neuron_p = 0.5     # 50% 神经元
  rank = 4
  targets = [fc1, fc2]  # 只调 MLP
  理由: 结构特征需要适度调整，但不必大动

Block 7, 8, 10, 11 (深层 — 冻结):
  frozen = True       # 完全不注入
  理由: 深层语义通用性强，对小目标帮助有限，冻结防过拟合
```

### 3.4 可训练参数对比

| 方案 | 注入层数 | 每层模块 | 可训练参数（相对） |
|------|---------|---------|-----------------|
| 全层 OPLoRA | 12 | qkv/proj/fc1/fc2 | 100% |
| NS-OPLoRA (层选择) | 8 | 差异化注入 | **~40-50%** |
| 其中浅层(0-2) | 3 | 全量 | ~30% (占比最高) |
| 其中 CE 层(3,6,9) | 3 | 仅 attn | ~15% |
| 其中过渡层(4,5) | 2 | 仅 MLP | ~5% |
| 深层(7,8,10,11) | 0 | 冻结 | 0% |

更少的参数总量，但关键层（浅层 + CE）的适应能力反而**更强**。

## 5. 预期效果

对反无人机跟踪：

1. **小目标跟踪精度提升**：浅层特征得到更强的任务特定适应
2. **速度不降级**：推理时 merge 为原始 Linear，零额外开销
3. **过拟合风险降低**：深层冻结 + 较少可训练参数
4. **GPU 显存节省**：更少的优化器状态 + 更少层的梯度计算
