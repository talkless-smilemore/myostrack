  ║                                                                      ║
  ║           WeightedSpectralProjection (WSP) 适配器层                   ║
  ║                                                                      ║
  ║    替换 ViT backbone 中的一个 nn.Linear，在不更新原始权重 W₀ 的        ║
  ║    前提下，通过低秩适配器 + 加权谱投影 + 门控机制学习小目标特征。         ║
  ║                                                                      ║

  ║    反无人机核心矛盾：                                                  ║
  ║      原始 W₀ 擅长识别"大物体 + 背景场景"（大奇异值方向），                ║
  ║      但小目标（<30px）的细节信息分布在中奇异值方向，                      ║
  ║      旧方法一刀切切断 top-k 方向会同时丢掉小目标细节。                   ║
  ║    本方案：按奇异值比值渐变保护 → 大方向受保护，小方向有适应空间。         ║
  ║    ████████████████████████████████████████████████████████████████   ║

  ║  ─────────────────────────────────────────────────────────────────    ║
  ║    xr = x - (x @ V_k) · D · V_kᵀ                                    ║
  ║                                                                      ║
  ║    物理含义：把 x 中"受保护的方向"去掉，只留下可自由适应的部分               ║
  ║                                                                      ║

  ║    │                                                        │     ║

  ║  ─────────────────────────────────────────────────────────────────    ║
  ║    ur = u - (u @ U_k) · D · U_kᵀ                                    ║
  ║                                                                      ║

  ║    │                                                        │     ║
  ║    │  如果没有输出投影，适配器可能改变输出的频率分布，              │     ║

  ║                                                                      ║
  ╚═══════════════════════════════════════════════════════════════════════╝

  ║                                                                      ║
  ║  步⑤  目标显著性门控 —— 让模型自己学会"什么通道对小目标有用"             ║
  ║  ─────────────────────────────────────────────────────────────────    ║
  ║    g = sigmoid(gate_logit)         每个输出通道 ∈ (0, 1)              ║
  ║    ug = ur × g                      门控 × 适配器输出                  ║
  ║                                                                      ║
  ║    ┌──────────────────────────────────────────────────────────┐     ║
  ║    │ ▶ 无人机意义                                              │     ║
  ║    │                                                        │     ║
  ║    │  大物体/背景占据图像 90%+ 像素 → 需要大量特征通道去编码。      │     ║
  ║    │  小无人机目标只占据 <1% 像素 → 只需少数判别通道。             │     ║
  ║    │                                                        │     ║
  ║    │  门控的作用就是"通道选择"：                                 │     ║
  ║    │    gate_logit[i] ≈ +3 → sigmoid ≈ 0.95 → 通道激活        │     ║
  ║    │    gate_logit[i] ≈ -3 → sigmoid ≈ 0.05 → 通道抑制        │     ║
  ║    │                                                        │     ║
  ║    │  🔑 细节显著性初始化（创新②）：                               │     ║
  ║    │  初始状态下，与小奇异值（细节）方向耦合强的通道就略打开。        │     ║
  ║    │  这给小目标特征一个"头马效应"，而不是从 0.5 等概率开始。          │     ║
  ║    │                                                        │     ║
  ║    │     detail_i = Σⱼ (Uk[i,j]² × (1-dⱼ))                  │     ║

  ║    │                                                        │     ║
  ║    │     小目标通道初始化 → sigmoid ≈ 0.55~0.65（提前打开）     │     ║
  ║    │     背景通道初始化   → sigmoid ≈ 0.35~0.45（提前关闭）     │     ║

  ║  ─────────────────────────────────────────────────────────────────    ║
  ║    out_final = out + (α/r) × ug                                     ║
  ║                                                                      ║
  ║    α/r 控制适配器更新的幅度：α 越大 → 微调力度越大                          ║
  ║    默认 α=8, rank=12 → 缩放因子 ≈ 0.67                             ║
