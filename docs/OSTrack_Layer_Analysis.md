# OSTrack 12层Block功能分析报告

> 基于输入扰动实验（`--perturb`），模型：`vitb_256_mae_ce_32x4_ep300`，数据来自 `results/attention_perturb/attention_perturbation_data.json`

---

## 实验方法说明

对同一张 search 图像施加三种扰动，比较扰动前后每层注意力的变化量：

| 扰动类型 | 破坏什么 | 保留什么 | Δ 高代表什么 |
|---------|---------|---------|------------|
| **Patch Shuffle**（打乱8×8小块） | 局部纹理连续性、相邻patch关系 | 全局颜色分布、大尺度形状 | 该层在做**局部patch关联**（纹理层） |
| **Gaussian Blur**（sigma=4.0高斯模糊） | 高频纹理细节（边缘、细纹路） | 低频轮廓、颜色 | 该层依赖**高频纹理信息** |
| **Phase Scramble**（FFT相位随机化） | 所有空间结构（位置、形状、朝向） | 纹理统计量、颜色分布 | 该层在做**全局空间推理**（语义/结构层） |

> 指标 Δ = ‖扰后热力图 − 原始热力图‖ / ‖原始热力图‖，范围 0~∞。Δ 越大 = 该层越依赖被破坏的那种信息。

## 核心发现：振荡交替，而非线性过渡

传统认知是"浅层→纹理，深层→语义"。但 OSTrack 的实际数据呈现出**纹理/结构交替振荡**的模式：

```
B0 ──SEMANTIC──→ B1 ──TEXTURE──→ B2 ──SEMANTIC──→ B3 ──SEMANTIC──→ B4 ──SEMANTIC──→ B5 ──TEXTURE──→ B6 ──MIXED──→ B7 ──MIXED──→ B8 ──TEXTURE──→ B9 ──TEXTURE──→ B10 ──TEXTURE──→ B11 ──TEXTURE
```

模型**不是在某个点做一次转换，而是在两种模式之间反复振荡。** 每种模式下的处理抽象层次逐步升高。CE 层（B3/B6/B9）恰好位于振荡的转折点附近。

## 逐层详细分析

### Block 0 — 空间嵌入层（SEMANTIC, gap=+0.427）

```
PatchShuffle=0.149   GaussBlur=0.004   PhaseScramble=0.576
```

- **对高频纹理完全免疫**（GaussBlur=0.004），对 patch 乱序几乎无感（0.149）
- **极度依赖空间结构**（PhaseScramble=0.576）
- **功能**：把 16×16 的 patch 当作一个整体空间单元来处理。patch embedding 的卷积投影已经将纹理压缩为统一 token，后续 transformer 看到的是"空间位置上的 token"，而非原始像素
- **微调建议**：❄ 冻结。只是嵌入投影，没有可学习的注意力，不需要改

---

### Block 1 — 局部关系引爆层（TEXTURE, gap=-0.176）

```
PatchShuffle=0.691 ↑  GaussBlur=0.018   PhaseScramble=0.515
```

- **PatchShuffle 从 B0 的 0.149 暴增到 0.691（+4.6倍）**——全模型变化最剧烈的跳变
- 这是进入 transformer 的第一个 block，开始学习相邻 patch 之间的局部关系
- patch shuffle 打乱了邻接关系 → 这层的注意力直接崩塌
- **功能**：在相邻 patch 之间建立局部上下文关联。把 B0 输出的孤立 token 连成"局部片段"
- **微调建议**：⭐⭐⭐ 高优先级。外观域迁移（RGB↔IR、白天↔夜晚）必须更新这层，因为局部纹理模式在这层形成

---

### Block 2 — 全局空间构建层（SEMANTIC, gap=+0.249）

```
PatchShuffle=0.382   GaussBlur=0.048   PhaseScramble=0.631 ↑
```

- PatchShuffle 大幅回落（0.691→0.382），PhaseScramble 上升到 0.631
- B1 建立了局部关联后，B2 把它们组装成更大尺度的空间理解
- **功能**：跨越局部 fragment，构建全局空间布局的初步表征
- **微调建议**：⭐⭐ 中优先级。如果目标类别（无人机型号）或拍摄视角改变，需要更新

---

### Block 3 — CE 空间筛选层（SEMANTIC, gap=+0.328）★CE

```
PatchShuffle=0.310 ↓  GaussBlur=0.222 ↑  PhaseScramble=0.638
```

- 第一次候选消除：用**空间结构信息**决定哪些 search token 值得保留
- PatchShuffle 降到 0.310（比 B1 降了一半），GaussBlur 跳升到 0.222——开始引入中频纹理信息辅助决策
- PhaseScramble 仍然最高（0.638）——空间结构主导
- **功能**：基于目标的空间位置关系，筛掉背景 token（保留 70%）
- **微调建议**：⭐⭐⭐ 高优先级。CE 决策直接影响后续所有层的输入质量。如果目标在 UAV 场景中的空间上下文变了（更远/更小/更乱背景），这层必须更新

---

### Block 4 — 空间结构精炼层（SEMANTIC, gap=+0.096）

```
PatchShuffle=0.389   GaussBlur=0.215   PhaseScramble=0.485
```

- CE 筛选后的巩固层。各项指标回落但结构敏感性仍占主导
- CE 削减了约 30% 的 token 后，B4 稳定剩余 token 的空间表示
- **功能**：精炼 CE 筛选后的 token 表示，巩固空间结构理解
- **微调建议**：⭐ 低优先级。过渡层，敏感性不高。可以冻结

---

### Block 5 — 局部关系重建层（TEXTURE, gap=-0.143）

```
PatchShuffle=0.569 ↑  GaussBlur=0.385 ↑  PhaseScramble=0.426
```

- CE 减少了 token 量后，这层重新建立剩余 token 之间的局部关联
- PatchShuffle 和 GaussBlur 双高——纹理指标全面回升
- **功能**：在稀疏化的 token 集合上重建局部 patch 关系
- **微调建议**：⭐⭐ 中优先级。如果红外图像中目标的局部纹理模式不同，需要适配

---

### Block 6 — CE 综合决策层（MIXED, gap=-0.013）★CE

```
PatchShuffle=0.517   GaussBlur=0.538 ↑↑↑  PhaseScramble=0.504
```

- **GaussBlur 全模型最高峰（0.538）**——这是唯一一个高频纹理指标登顶的层
- 三种扰动的影响力几乎完全相等（0.517 ≈ 0.538 ≈ 0.504）
- 第二次 CE 决策同时参考纹理、高频细节、空间结构三类信息
- **功能**：最全面的综合决策点。CE 在此兼顾局部纹理和全局结构
- **微调建议**：⭐⭐⭐ 最高优先级。这是全模型最重要的决策层，任何领域迁移都必须更新

---

### Block 7 — 信息融合枢纽（MIXED, gap=+0.020）

```
PatchShuffle=0.629 ↑  GaussBlur=0.213   PhaseScramble=0.649 ↑
```

- **综合敏感性最强的单层**——PatchShuffle=0.629，PhaseScramble=0.649，两者都接近全模型最高值
- GaussBlur 回落（0.538→0.213），说明高频纹理的重要性下降，模型回到"纹理+结构"双轨融合
- **功能**：纹理和空间结构信息在这里深度融合，是特征集成的关键枢纽
- **微调建议**：⭐⭐⭐ 最高优先级。最重要的单层。OPLoRA 必须覆盖

---

### Block 8 — 纯局部关联层（TEXTURE, gap=-0.247）

```
PatchShuffle=0.449   GaussBlur=0.192   PhaseScramble=0.202 ↓↓↓
```

- **PhaseScramble 降到全模型最低（0.202）**——这层几乎不依赖全局空间结构
- 全模型最"纯"的纹理层。只在 token 级别做局部运算，不关心物体在哪、形状如何
- **功能**：纯局部的 token 级关联。独立于物体的全局位置和形状
- **微调建议**：⭐⭐ 中优先级。如果场景有大量遮挡或背景杂乱，这层需要更新来维持局部连续性

---

### Block 9 — CE 纹理筛选层（TEXTURE, gap=-0.120）★CE

```
PatchShuffle=0.713 ↑↑↑  GaussBlur=0.173   PhaseScramble=0.593
```

- **PatchShuffle 全模型最高峰（0.713）**——纹理敏感性的极致
- 最后一次候选消除，用局部纹理连续性做筛选决策
- PhaseScramble 也较高（0.593）——仍然参考空间信息，但纹理主导
- **功能**：基于局部纹理连续性和目标外观做最终的 token 筛选（保留 70%）
- **微调建议**：⭐⭐⭐ 最高优先级。**外观风格迁移（RGB↔IR、晴天↔雾天）最需要更新的一层。** PatchShuffle 峰值说明这层的功能核心是"目标看起来像模板吗？"

---

### Block 10 — 细化微调层（TEXTURE, gap=-0.024）

```
PatchShuffle=0.448   GaussBlur=0.374 ↑  PhaseScramble=0.424
```

- 接近混合态（gap 仅 -0.024）。GaussBlur 重新上升至 0.374——做最后的中频纹理精炼
- 各项指标趋于平衡，表明这层在做最后的综合微调
- **功能**：最终的特征精细化，处理 CE 筛选后的残差
- **微调建议**：⭐ 低优先级。Rank 可以设低一些，但不建议完全冻结

---

### Block 11 — 最终稳定输出层（TEXTURE, gap=-0.044）

```
PatchShuffle=0.468   GaussBlur=0.133 ↓  PhaseScramble=0.424
```

- 所有敏感性指标全面下降——特征已经成形，扰动对输出的影响有限
- GaussBlur 降到 0.133，说明高频纹理信息已经完成其在模型中的作用
- **功能**：输出最终的 token 表示，供 head 生成 bounding box
- **微调建议**：❄ 冻结。对扰动不敏感，特征已经稳定。可以作为冻结候选

## 统计摘要

```
纹理敏感性 (patch shuffle)  浅层→深层:  0.407 → 0.543  (↑ 深层反而更高)
高频敏感性 (gaussian blur)   浅层→深层:  0.023 → 0.227  (↑ 全程很低)
结构敏感性 (phase scramble)  浅层→深层:  0.574 → 0.480  (↓ 略降，全程高)

全层平均 patch_shuffle:   0.475
全层平均 phase_scramble:  0.527

★ 结构主导从 Block 0 开始，无纹理→语义转换点。
  Patch embedding 消除了纹理信号，所有层都是结构驱动的。
```

## OPLoRA 配置建议

### 若只能选 5 层（5-layer OPLoRA）

```
B7, B6, B9, B1, B3
```

覆盖：三个 CE 决策点（B3/B6/B9）＋ 信息融合枢纽（B7）＋ 局部关系入口（B1）

### 若只能选 3 层（最小配置）

```
B7, B6, B9
```

覆盖最高敏感性的融合层 + 核心 CE 决策点

### 若 rank 可逐层分配

| 层 | B0 | B1 | B2 | B3 | B4 | B5 | B6 | B7 | B8 | B9 | B10 | B11 |
|----|-----|-----|-----|-----|-----|-----|-----|-----|-----|-----|-----|-----|
| Rank | 0 | 8 | 4 | 6 | 2 | 4 | 10 | 10 | 4 | 8 | 2 | 0 |

> Rank 值基于综合敏感性的比例分配，0 = 冻结。
